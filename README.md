# Komari 服务器地区手动修正插件 1.1.5

本版本在 1.1.3 的基础上增加匹配方式选择：**按节点名称**或**按 UUID**。同一时间只使用所选的一种方式。

## 配置方法

在插件配置中选择「地区修正匹配方式」，然后在规则框内每行填写一条规则，格式均为 `匹配值=地区代码`。

### 方式一：按节点名称匹配

```text
Taxi | LAX Mini=US
东京节点=JP
香港节点=HK
```

节点名称优先精确匹配，其次尝试包含匹配。

### 方式二：按 UUID 匹配

```text
11111111-2222-3333-4444-555555555555=US
66666666-7777-8888-9999-aaaaaaaaaaaa=JP
```

请把示例 UUID 替换成 Komari 中该节点实际使用的 UUID。UUID 模式仅精确匹配，不做包含匹配；插件会检查对象中的 `uuid`、`client_uuid`、`clientUuid`、`agent_uuid` 等明确 UUID 字段。普通 `id` 字段不会被当作 UUID。

## 生效方式

保存配置后刷新 Komari 页面。插件继续使用 1.1.3 的 HTTP `/api/*` 响应与 WebSocket `/api/*` 发送钩子，并在日志中输出当前匹配模式及实际修改数量。日志中的 `loaded N rule(s)` 仅表示规则已读取；`patched N node object(s)` 表示实际匹配并修改了对象。

## 注意

UUID 必须与 API 返回对象中的 UUID 字段完全一致。若节点对象并不携带上述 UUID 字段，UUID 规则不会命中；此时请核对该节点 API 数据中的字段名称。插件覆盖常见国家/地区代码字段，不会修改 IP 地址或经纬度。
